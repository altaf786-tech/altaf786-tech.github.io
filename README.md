# Mohammed Altaf — Data Analyst Portfolio

A responsive, modern dark-blue portfolio website built with plain HTML, CSS and JavaScript. Designed for GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling and dashboard illustration
- `script.js` — mobile navigation and current year
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing

## Publish with GitHub Pages (free)

1. Create a **new public repository** on GitHub named `altaf786-tech.github.io`.
2. Upload all files from this folder to the repository root (not the ZIP itself).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** (or `master`) and folder **/(root)**, then Save.
6. Wait a few minutes. Your website should appear at:
   `https://altaf786-tech.github.io/`

## Before publishing
- In `index.html`, replace the LinkedIn homepage link with your direct LinkedIn profile URL.
- Add a professional email address if you want recruiters to contact you directly.
- The dashboard graphic is illustrative sample data, not a claim about a real business project.
- The Excel, Python and Power BI cards describe your current toolkit. Add dedicated project cards when those case studies are completed and uploaded.
